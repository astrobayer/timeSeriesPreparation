timeSeriesPreparation.readNetcdf

A file of exportNetcdf back as a struct: time, observations, weights, layers, residual, events, attributes.

Syntax

d = timeSeriesPreparation.readNetcdf(file)

Description

The reader of the X-18 exchange format (CONCEPT 5.2; HANDOVER X-18). It reads the layout that exportNetcdf writes, schema_version "1": the observation and residual variables named by the global attributes observation_variables and residual_variables, in that order; layers decoded from their bits by flag_masks and flag_meanings; the events, when event_count is not -1, rebuilt as a qc.eventTable with UTC epochs (GPS minus the leap seconds, as run). It returns a struct, not an Arc: an Arc is built from the L1B reader's metadata, which the file keeps only as attributes.

Inputs

namesizetypedefaultdescription
file1,1string—- A NetCDF file written by exportNetcdf.

Outputs

namesizetypedefaultdescription
d1,1struct—- Fields: t (K,1) int64 GPS ns; obs (K,M) double; names, units (1,M) string; weights (K,1) double; filled (K,1) logical; layers (1,1) struct of (K,1) logical; residual, [] or a struct with obs, names (without the prefix) and units; events, [] or an (N,8) qc.eventTable; attributes (1,1) struct, the global attributes.

Accuracy

Exact for t, obs, weights, filled, layers and the residual (the values are read as stored). Event epochs to about 1 microsecond (see exportNetcdf).

Errors

timeSeriesPreparation:readNetcdf:fileNotFoundInputfile does not exist.

Example

Export a five-sample arc and read its time and observations back.

t = int64(7306 * 86400 - 43200 + 18) * int64(1e9) + int64(0:4)' * int64(1e9);
aux = struct("obsNames", {{'lin_accl_x'}}, "variableNames", {{'lin_accl_x'}}, "variableFieldNames", {{'lin_accl_x'}}, "variableUnits", struct("lin_accl_x", "m/s2"), "fileName", "ACT1B_2020-01-02_C_04.txt", "product", "ACT1B");
f = tempname + ".nc";
info = timeSeriesPreparation.exportNetcdf(f, timeSeriesPreparation.Arc(t, zeros(5, 1), aux), Metadata = struct("creator", "A. Author"));
d = timeSeriesPreparation.readNetcdf(f);
delete(f, info.prov);

Limitations

Reads schema_version "1" only; files of other writers refuse.
