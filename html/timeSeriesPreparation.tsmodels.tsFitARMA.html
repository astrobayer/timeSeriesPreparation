timeSeriesPreparation.tsmodels.tsFitARMA

Fit an ARMA(p,q) model: tsFitArima(x, p, 0, q, ...).

Syntax

model = timeSeriesPreparation.tsmodels.tsFitARMA(x, p, q)
model = timeSeriesPreparation.tsmodels.tsFitARMA(x, p, q, Method = "css")

Description

Shorthand for the ARMA model phi(B) (x_t - mu) = theta(B) e_t, fitted by timeSeriesPreparation.tsmodels.tsFitArima with d = 0; the options given are passed on unchanged, and tsFitArima's defaults apply otherwise. The default is exact Gaussian ML by a Kalman filter, which accepts NaN gaps; Method "css" gives conditional sum of squares. Both polynomials are stationary and invertible by construction (PACF reparametrisation, see tsFitArima).

Accuracy

That of tsFitArima, which it calls; unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Errors

(none of its own) The errors of timeSeriesPreparation.tsmodels.tsFitArima pass through, and so do tsFitArima's refusals of an option outside its domain.

Example

ARMA(1,1) with phi = 0.5, theta = 0.4 and zero mean, by CSS.

x = filter([1 0.4], [1 -0.5], randn(RandStream("twister", "Seed", 7), 300, 1));
model = timeSeriesPreparation.tsmodels.tsFitARMA(x, 1, 1, Method = "css", Constant = false);

Limitations

Those of tsFitArima. Options passed as one struct (inputParser's StructExpand) are no longer accepted; pass name-value pairs.
