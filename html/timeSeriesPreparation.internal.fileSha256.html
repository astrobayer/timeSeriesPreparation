timeSeriesPreparation.internal.fileSha256

SHA-256 of a file's bytes, as 64 lowercase hex digits.

Syntax

h = timeSeriesPreparation.internal.fileSha256(file)

Description

The integrity record of a campaign's day files (X-15, CONCEPT 5.2): the plain SHA-256 of the bytes, as sha256sum prints it, so a file can be checked outside MATLAB against the manifest. It differs from internal.contentHash, which hashes MATLAB values through a tagged byte stream. The file is read whole (java.security.MessageDigest).

Inputs

namesizetypedefaultdescription
file1,1string—- Path of an existing file.

Outputs

namesizetypedefaultdescription
h1,1string—- 64 lowercase hexadecimal digits.

Accuracy

Exact. TestCampaign pins the FIPS 180-4 values: "abc" gives ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad, the empty file e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855.

Errors

identifiercausecondition
timeSeriesPreparation:fileSha256:fileNotFoundInputfile cannot be opened for reading.

Example

The SHA-256 of a three-byte file.

f = tempname; fid = fopen(f, "w"); fwrite(fid, 'abc'); fclose(fid);
h = timeSeriesPreparation.internal.fileSha256(f);
delete(f);

Limitations

The whole file is held in memory once; a day file of run is tens of MB.

References

NIST FIPS 180-4, Secure Hash Standard (2015), SHA-256 and example B.1; docs/CONCEPT.md 5.2 (per-day storage, manifest).
