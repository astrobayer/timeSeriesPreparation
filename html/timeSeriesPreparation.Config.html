timeSeriesPreparation.Config

Instrument settings in nine sections, strict about field names.

Syntax

cfg = timeSeriesPreparation.Config()
cfg = timeSeriesPreparation.Config(arc)
cfg = set(cfg, section, field, value)
s   = toStruct(cfg)

Description

The settings of every stage, in the sections of CONCEPT 5: mask, qc, crn, align, fill, noise, unc, drivers, run. Each section has a schema, the list of fields it knows; set refuses a section or a field outside it, so a misspelt option fails instead of being silently ignored. Config(arc) records the arc's mission and product and returns the preset for that product (CONCEPT 5).

Each stage adds its fields, defaults and presets in its own work package; the other sections are still empty. An option whose default would be an assumption defaults to empty (R5). Applications take a Config as 'Preproc' and hash it with their own options; toStruct gives them a plain struct to hash.

crn (X-04): field preset, the crnKernel preset the product was filtered with in L1B processing - "ACC" for ACC1B (GRACE) and ACT1B (GRACE-FO), "KBR" for KBR1B (R-1 App. B; R-2 PDF p. 20). Any other product leaves it "" (not known, so not assumed).

Accuracy

Not applicable, because the class computes no number; values are stored as given.

Errors

Example

The empty skeleton as a plain struct, e.g. for hashing.

cfg = timeSeriesPreparation.Config();
s = toStruct(cfg);

Limitations

Only crn.preset exists so far; set refuses every other field until the stages define theirs.
