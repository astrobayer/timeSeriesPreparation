timeSeriesPreparation.qc.eventTable

Canonical event table (schema authority) for quality-control results.

Syntax

T = timeSeriesPreparation.qc.eventTable()
T = timeSeriesPreparation.qc.eventTable(tStart, tEnd, class, axis, amplitude, sigma, source, confidence)

Description

Every detector returns this table, so the mask builder and the calibration read one schema. Without arguments it returns the empty table (the schema). Classes and their downstream use: "outlier" (isolated samples, masked), "impulse" (CRN-shaped pulse, masked, assigned to THR1B or a twang), "jump" (step in level or slope, a Heaviside column in the calibration, never masked). An amplitude and sigma of NaN mean not estimated, which is what a THR1B firing carries; confidence is a probability and never NaN. Ported from NonGravForces.qc 0.12.0 (X-05); unchanged (X-05b).

Inputs

namesizetypedefaultdescription
tStartN,1datetime—- UTC, first affected sample.
tEndN,1datetime—- UTC, last affected sample (tStart for a point).
classN,1string—- "outlier", "impulse" or "jump".
axisN,1string—- "x", "y", "z" or "all".
amplitudeN,1double—- Estimated size (step size for jumps), units of the data; NaN = not estimated.
sigmaN,1double—- 1-sigma of amplitude, >= 0; NaN with the amplitude.
sourceN,1string—- "THR1B", "MAS1B", "eclipse", "heater", "magnetorquer" or "unassigned".
confidenceN,1double—- In [0, 1], finite.

Outputs

namesizetypedefaultdescription
TN,8table—- Variables tStart, tEnd, class, axis, amplitude, sigma, source, confidence, in that order.

Accuracy

Not applicable, because the function computes no number; values are stored as given.

Example

A jump and an outlier.

t = datetime(2020, 1, 1, "TimeZone", "UTC") + seconds([10; 20]);
T = timeSeriesPreparation.qc.eventTable(t, t, ["outlier"; "jump"], ["x"; "all"], [1e-8; 2e-9], [1e-9; 1e-9], ["unassigned"; "eclipse"], [0.9; 0.5]);

Limitations

The source set is closed; a new source is a schema change.
