timeSeriesPreparation.report

Figures and a self-contained HTML page of a run result; for a campaign, one page per day and an index.

Syntax

out = timeSeriesPreparation.report(res)
out = timeSeriesPreparation.report(res, Visible = "off", ExportTo = folder)
out = timeSeriesPreparation.report(campaignRes, ExportTo = folder)

Description

The instrument report (X-11, CONCEPT 10.1; owner decisions 2026-09-26). It reads what run returned and computes nothing but the spectra it plots; it never calls run. Four figures: series per axis the observation and the reference, each with its mean removed, and the residual; below, a timeline of every layer, the missing (NaN) samples and the filled ones. events flags.events over time, one row per class, coloured by source, marked by axis. noise per axis the PSD of the residual (spectral.powerSpectrum, Welch, on the longest stretch without NaN) against the fitted model's PSD (spectral.arma2psd of diagnostics.noise), and the squared reference ASD of noiseReference when the product has one: ACT1B and ACC1B ("ACC", axis from the column name), KBR1B and LRI1B (range, rate and acceleration columns). alignment checkAlignment's r(lag) per axis with the refined lag, and correlate's r(lag) with its interval per axis and driver, when those stages ran. A panel whose stage did not run shows why (diagnostics.skipped), and out.notes says the same.

With ExportTo, the figures go to series.png, events.png, noise.png and alignment.png at 200 dpi (exportgraphics), and report.html is written: one page with no outside references. It holds the summary (mission, satellite, product, release, files, epochs, stages, weight fraction, filled samples, events, alignment verdicts, config hash, toolbox version), the skipped stages, the events (the first 200), the provenance and the four PNGs as data URIs.

A campaign result (run on an Arc array) needs ExportTo. Each arc that ran is reported into ExportTo/<day>/ with Visible "off" and its figures are closed. index.html holds the campaign summary (status, identifier, weight fraction, events, files, SHA-256), each day linked.

Accuracy

The figures show the stored values. The spectra are estimates: Welch with up to 16 averages (Hann, 50 % overlap) on the longest finite stretch, the model PSD on 1024 frequencies.

Example

Report a ten-minute three-axis run without showing the figures.

t = int64(7306 * 86400 - 43200 + 18) * int64(1e9) + int64(0:599)' * int64(1e9);
names = {'lin_accl_x', 'lin_accl_y', 'lin_accl_z'};
aux = struct("obsNames", {names}, "variableNames", {names}, "variableFieldNames", {names}, "variableUnits", struct('lin_accl_x', 'm/s2', 'lin_accl_y', 'm/s2', 'lin_accl_z', 'm/s2'), "fileName", "ACT1B_2020-01-02_C_04.txt", "product", "ACT1B");
s = 1e-7 * sin(2 * pi * (0:599)' / 300) * [1 1 1];
arc = timeSeriesPreparation.Arc(t, s + 1e-9 * randn(RandStream("twister", "Seed", 1), 600, 3), aux);
res = timeSeriesPreparation.run(arc, Reference = timeSeriesPreparation.Arc(t, s, aux));
out = timeSeriesPreparation.report(res, Visible = "off");
close([out.figures.series out.figures.events out.figures.noise out.figures.alignment]);

Limitations

No pixel reference is kept (renderers differ between MATLAB updates), so the figures are tested for their content contract and speed only. The page embeds the PNGs, about 0.1 to 0.5 MB each.
