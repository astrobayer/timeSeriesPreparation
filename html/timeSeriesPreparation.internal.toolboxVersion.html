timeSeriesPreparation.internal.toolboxVersion

The toolbox version, read from its one authority, Contents.m.

Syntax

v = timeSeriesPreparation.internal.toolboxVersion()

Description

Returns the version stated in +timeSeriesPreparation/Contents.m, the single version source of GUIDE section 3, which the shared audit also checks every help footer against. Provenance records (Arc) cite it, so a result names the release that produced it without a second literal that could drift.

Inputs

(none)

Outputs

namesizetypedefaultdescription
v1,1string—- Version as MAJOR.MINOR.PATCH, e.g. "0.0.0".

Accuracy

Not applicable, because the function computes no number; it returns the text of the Version line verbatim.

Errors

identifiercausecondition
timeSeriesPreparation:toolboxVersion:noVersionVersion sourceContents.m holds no "% Version x.y.z" line.

Example

The version this checkout reports.

v = timeSeriesPreparation.internal.toolboxVersion();

Limitations

Reads the file on every call; callers that need it per sample should read it once.

References

docs/GUIDE.md section 3 (one version source).
