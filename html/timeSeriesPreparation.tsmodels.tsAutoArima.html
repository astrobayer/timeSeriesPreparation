timeSeriesPreparation.tsmodels.tsAutoArima

Grid search over ARIMA(p,d,q) orders minimising AIC or BIC.

Syntax

[best, table] = timeSeriesPreparation.tsmodels.tsAutoArima(x)
[best, table] = timeSeriesPreparation.tsmodels.tsAutoArima(x, maxP, maxQ, d)
[best, table] = timeSeriesPreparation.tsmodels.tsAutoArima(x, 3, 3, 0, Criterion = "bic", Method = "css")

Description

Fits every ARIMA(p,d,q) with 0 <= p <= maxP and 0 <= q <= maxQ, except p = q = 0, by timeSeriesPreparation.tsmodels.tsFitArima, and returns the model with the smallest information criterion. The options other than Criterion that are given are passed on to tsFitArima, whose defaults apply otherwise. An order whose fit raises an error is skipped silently. The table lists every fitted order, sorted by the criterion (ties keep the grid order: p outer, q inner). AIC = 2 nll + 2 k and BIC = 2 nll + k log(nObs), with k the number of coefficients plus one, as tsFitArima computes them; d is fixed, so all candidates share one differenced series. Base MATLAB only.

Accuracy

Each candidate is a tsFitArima fit; unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit. The selection is only as good as the individual optima (fminsearch from four starts).

Example

An AR(1) series: the lowest-BIC order with p <= 2, q <= 1, by CSS.

x = filter(1, [1 -0.6], randn(RandStream("twister", "Seed", 8), 300, 1));
[best, table] = timeSeriesPreparation.tsmodels.tsAutoArima(x, 2, 1, 0, Criterion = "bic", Method = "css");

Limitations

The cost is (maxP + 1)(maxQ + 1) - 1 fits; exact ML makes a large grid slow. d is not searched. A failing order is skipped without a message. Options passed as one struct are not accepted; pass name-value pairs.
