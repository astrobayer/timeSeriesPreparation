timeSeriesPreparation.tsmodels.tsForecast

h-step forecasts and prediction intervals of an (S)ARIMA model.

Syntax

[yhat, se, lo, hi] = timeSeriesPreparation.tsmodels.tsForecast(model, h)
[yhat, se, lo, hi] = timeSeriesPreparation.tsmodels.tsForecast(model, h, alpha)
[yhat, se, lo, hi] = timeSeriesPreparation.tsmodels.tsForecast(model, h, 0.05, Bootstrap = true, NBoot = 5000, Seed = 1)

Description

Point forecasts on the original scale, their standard errors and (1 - alpha) prediction intervals, for a model from tsFitArima (and its wrappers tsFitAR, tsFitMA, tsFitARMA, tsAutoArima) or from tsFitSarima. Three paths, chosen from the model's fields: ARIMA The ARMA recursion runs on the differenced series xd with future innovations set to zero. The forecast error variance is sigma^2 cumsum(psi.^2) with the MA(inf) psi-weights; for d > 0 the path is integrated d times from the last observed values and psi is summed d times, so the one-step variance is sigma^2 exactly. SARIMA (fields arExpanded, maExpanded, diffInfo) The same on the expanded ARMA; the path is re-integrated through Delta(B) = (1-B)^d (1-B^s)^D from the observed tail, and the variance uses Psi(B) = psi(B) / Delta(B). gaps (field obs not all true; d = D = 0) The missing-data Kalman filter of the fit runs to the end of the record, from the stationary covariance of timeSeriesPreparation.internal.dlyap (tolerance 1e-14, 60 doublings), and the state is projected forward; se = sqrt(sigma^2 P(1,1)). The Gaussian interval is yhat -/+ z se with z the standard normal quantile at 1 - alpha/2 (Acklam's rational approximation). With Bootstrap the interval is instead the empirical alpha/2 and 1 - alpha/2 quantile of yhat + err_k, err_k = sum_j Psi_(j+1) e*_(k-j), over NBoot draws e* with replacement from the centred finite model residuals; it captures skewed or heavy-tailed innovations. se stays the Gaussian psi-weight standard error. Base MATLAB only.

Accuracy

Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit. The sigtools HANDOFF (section 3) records: the seasonal path against a 150k-200k-run Monte Carlo for SARIMA(1,0,0)(1,1,0)_4 and (1,1,1)(1,1,0)_4 gives the point forecast to Monte-Carlo noise, se within about 0.3 % and the one-step se exactly; the bootstrap half-width reproduces the Gaussian one to about 1-3 % for Gaussian residuals, with about nominal out-of-sample coverage for Gaussian and skewed innovations. The normal quantile is good to about 1e-9 (the source's comment on its Acklam approximation).

Example

Ten steps ahead of a CSS-fitted AR(1), with 95 % Gaussian intervals.

x = filter(1, [1 -0.6], randn(RandStream("twister", "Seed", 4), 200, 1));
[yhat, se, lo, hi] = timeSeriesPreparation.tsmodels.tsForecast(timeSeriesPreparation.tsmodels.tsFitArima(x, 1, 0, 0, Method = "css"), 10);

Limitations

The intervals ignore the uncertainty of the estimated coefficients. The Gaussian interval assumes Gaussian innovations. The bootstrap is not available for gap-fitted models and, without Seed, draws from and advances the global random stream. alpha must be a scalar. Options passed as one struct (inputParser's StructExpand) are no longer accepted; pass name-value pairs.
