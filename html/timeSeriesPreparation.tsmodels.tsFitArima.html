timeSeriesPreparation.tsmodels.tsFitArima

Fit an ARIMA(p,d,q) model by exact ML, CSS or Yule-Walker.

Syntax

model = timeSeriesPreparation.tsmodels.tsFitArima(x, p, d, q)
model = timeSeriesPreparation.tsmodels.tsFitArima(x, p, d, q, Method = "css", Constant = false)

Description

The one ARIMA estimator of the package; tsFitAR, tsFitMA, tsFitARMA and tsAutoArima call it. It fits phi(B) (1-B)^d (x_t - mu) = theta(B) e_t, e_t ~ N(0, sigma^2), phi(B) = 1 - phi_1 B - ... - phi_p B^p, theta(B) = 1 + theta_1 B + ... + theta_q B^q; (p,0,0) is AR(p), (0,0,q) MA(q), (p,0,q) ARMA(p,q). x is differenced d times first (tsDiff); the mean mu (Constant) is that of the differenced series.

Methods: "exact" exact Gaussian ML (default). A Kalman filter on the Harvey state space of dimension r = max(p, q+1), started from the stationary covariance P = T P T' + R R' (the shared doubling solver timeSeriesPreparation.internal. dlyap, tolerance 1e-14, 60 doublings, Kronecker fallback), with sigma^2 concentrated out. "css" conditional sum of squares, the first max(p,q) residuals set to zero. "yw" Yule-Walker, pure AR only: a closed-form fast path, the mean is the sample mean, no optimiser, no standard errors.

For exact ML and CSS the AR and the MA block are optimised in an unconstrained space: tanh maps each value to a partial autocorrelation in (-1, 1), clamped to +/-0.999, and the Durbin-Levinson recursion turns these into coefficients. Every trial polynomial is therefore stationary and invertible by construction. fminsearch (TolX = TolFun = 1e-8, MaxFunEvals 2000 (p+q+2)) runs from four starts: a Yule-Walker seed, a white-noise seed and two seeds perturbed by 0.3 randn; the lowest negative log-likelihood wins. Standard errors come from the observed-information Hessian of the penalty-free objective in the natural parameters: central differences at steps h = 1e-3 max(|theta|, 1) and h/2, combined by Richardson extrapolation, with an eigenvalue repair when the inverse is not positive definite. AIC = 2 nll + 2 k and BIC = 2 nll + k log(nObs), with k the number of coefficients plus one for sigma^2.

Gaps: NaN marks a missing sample on a regular time grid. With the exact method the Kalman filter only predicts at a gap and accrues no likelihood term there, which gives the exact ML estimate on the observed data. Gaps require d = 0 and Method "exact"; resid is NaN there and nObs counts the observed samples. Base MATLAB only.

Accuracy

Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit. The sigtools HANDOFF (section 3) records independent NumPy re-derivations: the exact AR(1) log-likelihood matches the closed-form Gaussian density to about 1e-12; the Richardson-Hessian standard error of an AR(1) matches sqrt((1 - phi^2)/n) to a ratio of 1.000; the PACF <-> coefficient round trip is exact; the doubling Lyapunov solve matches the Kronecker solve to about 1e-15. The optimum itself is only as good as fminsearch from four starts (TolX 1e-8).

Example

AR(1) with phi = 0.6 and zero mean: exact ML recovers ar near 0.6.

x = filter(1, [1 -0.6], randn(RandStream("twister", "Seed", 1), 200, 1));
model = timeSeriesPreparation.tsmodels.tsFitArima(x, 1, 0, 0, Constant = false);

Limitations

The two perturbed starts draw from the global random stream, whose state is restored afterwards; the fit therefore depends on the current rng state (set rng for a reproducible fit). The exact likelihood costs O(n r^3) per evaluation; fminsearch needs hundreds of evaluations, so large p + q is slow. Gaps and differencing do not mix. Options passed as one struct (inputParser's StructExpand) are no longer accepted; pass name-value pairs.
