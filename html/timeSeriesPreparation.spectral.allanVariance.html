timeSeriesPreparation.spectral.allanVariance

Overlapping Allan variance and deviation, with confidence bounds and slopes.

Syntax

[tau, avar, adev, info] = timeSeriesPreparation.spectral.allanVariance(x, fs)
[tau, avar, adev, info] = timeSeriesPreparation.spectral.allanVariance(x, fs, m, ciLevel)

Description

Fully overlapping Allan variance of rate-type series (IEEE 1139; Riley 2008), one column per channel, through the phase construction

theta(k) = sum_(j<k) x(j)/fs, theta(1) = 0 sigma^2(tau) = sum_(i=1..K) (theta(i+2m) - 2 theta(i+m) + theta(i))^2 / (2 tau^2 K), K = N - 2m, tau = m/fs.

Every cluster start is used, which gives far more confidence per tau than non-overlapping blocks of the same record. The confidence bounds use the chi-square construction edf*avar/chi2inv. The chi-square quantiles come from the Wilson-Hilferty approximation through erfinv, so no toolbox is needed. The equivalent degrees of freedom are the noise-agnostic large-sample value edf = 3(N-1)/(2m) - 2(N-2)/N, which is indicative only. The local log-log slope identifies the noise type: white -1/2, flicker 0, random walk +1/2, ramp +1, quantisation -1. The bias instability is 0.664 min(adev) (the IEEE convention).

Since X-02 the function computes only; plotAllanVariance draws the result (owner decision 2026-09-23, clean break). The numbers are v1.3.1's, unchanged.

Accuracy

The estimator is exact arithmetic on the phase sums. The bounds rest on two approximations: the edf formula is noise-type agnostic (Riley 2008 gives noise-specific values), and the Wilson-Hilferty chi-square quantile. At the default 1-sigma level that quantile errs by < 0.6 % for edf >= 3. At 95 % its lower 2.5 % quantile errs by 16 % at edf 3, 4 % at edf 5 and 0.7 % at edf 10 (measured against an exact quantile, 2026-09-23), so the widest-tau bounds are rough. Unchanged from sigtools v1.3.1, and TestSigtoolsEquivalence holds it bit for bit.

Errors

(none) Inputs outside their domain are refused by the arguments block with a MATLAB: identifier.

Example

White noise: the Allan deviation falls with slope -1/2.

x = randn(RandStream("twister", "Seed", 1), 10000, 1);
[tau, ~, adev, info] = timeSeriesPreparation.spectral.allanVariance(x, 10);

Limitations

Rate-type (frequency) data only; phase data must be differenced first. NaN is not handled: a NaN poisons every tau whose clusters touch it.

References
