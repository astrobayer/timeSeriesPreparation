timeSeriesPreparation.spectral.synthTimeSeries

Generate stationary noise from a PSD or an ARMA model.

Syntax

[x, t, info] = timeSeriesPreparation.spectral.synthTimeSeries("psd", f, S, Fs, N)
[x, t, info] = timeSeriesPreparation.spectral.synthTimeSeries("arma", b, a, Fs, N)
x = timeSeriesPreparation.spectral.synthTimeSeries("psd", f, S, Fs, N, NColumns = 4, Seed = 1)

Description

Synthesises N samples of a real, zero-mean Gaussian series at Fs that is stationary from the first sample: there is no filter warmup and no burn-in to discard.

Mode "psd" uses the randomised-phase spectral representation. The one-sided target S(f) is interpolated onto the rFFT grid f_k = k Fs/N (log-log if the grid is log-spaced and mostly positive, else linear; zero outside [min f, max f]). Each bin gets a complex Gaussian amplitude with E|X_k|^2 = S_k Fs N/2, DC and Nyquist are real with the full power S_k Fs N, and the half-spectrum is inverted with Hermitian symmetry.

Mode "arma" runs x[n] = filter(b, a, w[n]), w white with variance NoiseVariance, in Harvey's companion state-space form. The initial state is drawn from the stationary distribution, whose covariance solves the discrete Lyapunov equation (doubling, tolerance 1e-14, 80 steps; timeSeriesPreparation.internal.dlyap), factored by Cholesky (eigen-decomposition if not positive definite).

The PSD scaling matches arma2psd and powerSpectrum: one-sided S with trapz(f,S) equal to the variance, so an arma2psd output fed back in reproduces the spectrum. With Seed, the global generator is seeded by rng(Seed) and restored on exit; without it, the global stream is used and advanced.

Accuracy

sigtools HANDOFF section 3 (NumPy re-derivation): the PSD path is unbiased (mean bias about 1e-5, error falling as 1/sqrt(M) over M realisations); the ARMA path variance matches theory; the ratio of first-block to last-block mean square is about 1.00 (no warmup); the Hermitian assembly is correct for even and odd N. A single realisation scatters around the target like any Gaussian estimate. Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Example

1000 samples of an ARMA(2,2) process at 500 Hz, reproducible.

[x, t, info] = timeSeriesPreparation.spectral.synthTimeSeries("arma", [1 -0.5 0.2], [1 -1.2 0.6], 500, 1000, NoiseVariance = 2, Seed = 1);

Limitations

Gaussian only: non-Gaussian higher moments are not reproduced. The PSD path is periodic with period N (circular), so the ACV wraps around. The draws use the global random stream (rng), not a RandStream argument; Seed makes a call reproducible. The ARMA path loops sample by sample in MATLAB and is slow for very long series.
