timeSeriesPreparation.crossval

Blocked cross-validation with a buffer, for serially correlated rows.

Syntax

[loss, info] = timeSeriesPreparation.crossval(x, lossFcn)
[loss, info] = timeSeriesPreparation.crossval(x, lossFcn, Folds = 5, Gap = [])

Description

Out-of-sample loss of a model on dependent samples (CONCEPT 6.1, row 7). Random K-fold splits leak information when neighbouring rows are correlated: a test row's neighbours sit in the training set. Here the rows are cut into Folds contiguous blocks of near-equal length (the first rem(N, Folds) blocks one row longer). For fold k the test rows are block k; the training rows are all others except the Gap rows on either side of the block, which neither set uses (hv-block cross-validation, Racine 2000, with v = 0).

lossFcn(xTrain, xTest) returns a 1 x L row. Both arguments are N x M, the full grid, with every row outside the set NaN. The time index therefore stays intact, and NaN is the only missing value (CONCEPT 5.2). lossFcn must treat NaN. No least-squares estimator lives here (CONCEPT 3.2): the application fits on xTrain and scores on xTest.

Gap [] takes the automatic block length of internal.blockLength (Politis & White 2004, Patton et al. 2009) per column, rounded up, the largest over the columns: the range over which rows are still dependent (owner decision 2026-09-23). No random numbers are used.

Accuracy

Exact partition: every row is tested exactly once, and no training row lies within Gap rows of its test block (TestCrossval checks both). se treats the fold losses as independent, which the buffer makes approximately true; it is a guide, not a confidence bound.

Example

Loss of the training mean as a predictor of the test rows.

x = filter(1, [1 -0.5], randn(RandStream("twister", "Seed", 4), 1000, 1));
mse = @(tr, te) mean((te - mean(tr, "omitnan")).^2, "omitnan");
[loss, info] = timeSeriesPreparation.crossval(x, mse, Folds = 5);

Limitations

Rows are assumed equally spaced. Folds are contiguous in the row order; a test block at the start or end has a buffer on one side only. The training set is not required to precede the test block (no forward-chaining).
