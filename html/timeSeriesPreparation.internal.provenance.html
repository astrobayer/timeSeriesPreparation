timeSeriesPreparation.internal.provenance

Metadata record that travels with every result of the qc units.

Syntax

p = timeSeriesPreparation.internal.provenance(unit)
p = timeSeriesPreparation.internal.provenance(unit, Options=s, Files=f)

Description

The port of NonGravForces.provenance (0.12.0, 3cc0123) for the units of +qc (X-05). It keeps the original's fields: which unit, which toolbox version, which dependencies, which option hash, which files, which warnings, a note and when. Two things differ, each for a reason: - dependencies is empty: the qc units call no other toolbox, and timeSeriesPreparation has no dependency report to ask; - optionHash is the exact 32-bit FNV-1a of jsonencode(Options) (internal.stageSeed). The original multiplies in double, which is inexact above 2^53, so the two hashes can differ.

Options

Outputs

namesizetypedefaultdescription
p1,1struct—- unit, toolboxVersion, dependencies (0x0 struct with name and version), optionHash (8 hex digits, "00000000" for no options), files, warnings, note, created (datetime, UTC).

Accuracy

Exact: the hash is integer arithmetic on the UTF-8 bytes of the JSON text.

Errors

(none)

Example

The record of a hampel call with its window.

p = timeSeriesPreparation.internal.provenance("qc.hampel", Options=struct("Window", 61));

Limitations

The hash follows jsonencode's text, so two structs with the same values in another field order hash differently.
