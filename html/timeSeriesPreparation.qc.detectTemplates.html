timeSeriesPreparation.qc.detectTemplates

Events of the template bank in a 3-axis residual, one mask per class.

Syntax

[events, info] = timeSeriesPreparation.qc.detectTemplates(r, Epoch = t, Satellite = "D")
[events, info] = timeSeriesPreparation.qc.detectTemplates(r, Epoch = t, Satellite = "C", Priors = thr, Threshold = 8)

Description

The labelled template bank of QC (CONCEPT 6.1 row 2, X-17; owner decisions 2026-09-26). The residual is high-passed as the bank was measured, r minus its 301-s moving median; NaN samples count as 0 and a window touching one is not evaluated. For each class of the bank and the given satellite, a 3-axis matched filter with the unit-norm template h gives c(t) = sum over axes and lags of h(l) r(t + l); its robust sigma s is 1.4826 times the MAD of c over the evaluable samples. Peaks of |c/s| at or above Threshold, at least one template length apart (largest first), each claim their neighbourhood; the positive ones are events (a negative peak, the inverted shape, is none, but blocks its sidelobes, which reach 15 to 26 sigma for a median event) of class "impulse", axis "all": amplitude (c/g) hp, the event's size at the template's largest sample hp (signed, m/s^2; g = the filter output of the template itself, so c/g = 1 is the bank's median event), sigma (s/g) |hp|. An event whose peak (lag 0, the THR1B record the bank is stacked on) lies within PriorWindow_s of a prior's tStart takes its source and confidence 1; the others are "unassigned" with confidence erf(score/sqrt(2)). Each class has a mask over its template's support (the lags where the template reaches 5 % of its peak) around every event; run adds it as layer "tpl" + the class name capitalised.

Accuracy

For white noise the score is standard normal away from gaps, so a threshold of 8 gives about 1e-15 false peaks per sample. A planted median-size thruster event in noise of 1.5e-10 m/s^2 scores about 100 (TestTemplates).

Example

A median thruster event planted in white noise is found at its epoch.

b = timeSeriesPreparation.qc.templateBank();
r = 1.5e-10 * randn(RandStream("twister", "Seed", 3), 3000, 3);
r(1440:1560, :) = r(1440:1560, :) + b.thruster.D;
t = datetime(2020, 1, 4, "TimeZone", "UTC") + seconds((0:2999)');
events = timeSeriesPreparation.qc.detectTemplates(r, Epoch = t, Satellite = "D");

Limitations

1 Hz epochs are assumed (the bank's lags are samples of 1 s). One class so far, thruster; the x column is 0 on C (HANDOVER X-17).
