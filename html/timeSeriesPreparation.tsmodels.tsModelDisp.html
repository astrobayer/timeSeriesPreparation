timeSeriesPreparation.tsmodels.tsModelDisp

Pretty-print a fitted ARIMA or SARIMA model summary.

Syntax

timeSeriesPreparation.tsmodels.tsModelDisp(model)

Description

A readable summary of a fit for the command window: the model type and method (flagged when the optimiser did not converge), each coefficient (mu, AR, MA and, for SARIMA, SAR, SMA) with its standard error, sigma^2, the log-likelihood with n and k, the observed count when samples are missing, AIC and BIC, and a Ljung-Box test of the residuals at L = min(20, max(1, floor(n/4))) lags with nParam = p + q (+ P + Q). Standard errors are shown only when the model carries a field stdErr; tsFitSarima fits do not compute them, so the column reads '-'. Base MATLAB only.

Inputs

namesizetypedefaultdescription
model1,1struct—- Fit from tsFitArima, tsFitAR, tsFitMA, tsFitARMA, tsFitSarima, tsAutoArima or tsAutoSarima.

Outputs

(none)

Accuracy

Not applicable, because it prints the model's numbers, rounded to the printed digits (%12.6g for coefficients, %.5g for standard errors), and a Ljung-Box value computed by tsLjungBox.

Errors

(none) A model that is not a 1x1 struct is refused by the arguments block, and a missing field by MATLAB, each with a MATLAB: identifier.

Example

Fit an AR(1) and print its summary.

x = filter(1, [1 -0.6], randn(RandStream("twister", "Seed", 4), 300, 1));
timeSeriesPreparation.tsmodels.tsModelDisp(timeSeriesPreparation.tsmodels.tsFitAR(x, 1));

Limitations

Output only; nothing is returned. Use tsCheckResiduals for the residual numbers.

References

G. M. Ljung, G. E. P. Box (1978), Biometrika 65(2), 297-303. sigtools v1.3.1 HANDOFF (docs/inputs).
