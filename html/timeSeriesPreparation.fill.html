timeSeriesPreparation.fill

Report the gaps of an arc, or fill the short ones by covariance collocation.

Syntax

[arc, info] = timeSeriesPreparation.fill(arc)
[arc, info] = timeSeriesPreparation.fill(arc, Method = "collocation", Model = nm, MaxGap = 10, Window = [])

Description

The gap stage (CONCEPT 6.1 row 8, 6.5). A sample is missing on an axis when it is NaN, has weight 0 or was filled before; each axis has its own gaps, a gap being a run of missing samples on the uniform grid. - Method "none" (the default, Q3): nothing changes; info.gaps reports every gap. Splitting the arc there is the caller's. - Method "collocation": each interior gap of at most MaxGap seconds is replaced by the optimal (least-squares) prediction under the covariance model, x_g = mu + C_go C_oo^-1 (x_o - mu), with the prediction variance diag(C_gg - C_go C_oo^-1 C_og). The conditioning samples x_o are the observed samples within W samples either side of the gap. The covariances are the Toeplitz entries Model.acv(|i - j| + 1), never extrapolated: W is at most floor((L - k + 1) / 2) for a gap of k samples and a model to lag L, so that every pair in the window has a lag <= L and the matrix used is the model's own. Window lowers W further. For an AR(p) model with W >= p the result equals the prediction from the whole record (the AR precision matrix is banded); for ARMA it converges as W grows (ACCURACY). - Method "reference" (a calibrated reference plus the collocated residual, CONCEPT 6.5) is deferred until the drivers exist (X-09) and refuses. Not filled, and reported with the reason: gaps touching the first or last sample ("edge", which would be extrapolation), gaps longer than MaxGap ("tooLong"), and gaps the model is too short to bridge ("beyondModel", W < 1).

The epochs stay. Filled values enter arc.obs, the row is flagged in arc.filled, and a "fill" entry is appended to the provenance (Arc.fillSamples). Every fit weighs filled rows 0 (CONCEPT 5). With Method "none" the arc is returned unchanged.

The model is noise's output or, e.g. from lsqvce, any struct with acv (L+1, M) in unit^2 at lags 0..L samples, dt (s) and mu (1, M) (CONCEPT 3.2: fill takes a covariance model; there is no estimator here).

Accuracy

A linear solve with the Cholesky factor of C_oo, whose condition is that of the model's covariance over 2W + 1 lags. An AR(1) one-sample gap equals phi/(1 + phi^2) (x_(t-1) + x_(t+1)) and an AR(1) bridge of k samples its closed form to rounding (NumPy: 6e-16). An ARMA(1,1) with phi 0.6, theta 0.5 and a 20-sample gap differs from the whole-record prediction by at most 1.4e-3, 1.4e-6, 1.1e-12 and 4.7e-15 standard deviations for L = 40, 60, 100 and 140 (NumPy, 200 realisations, 2026-09-24): the error decays like max(|phi|, |theta|)^W. The fill is optimal only as far as the model is right.

Example

An AR(1) at 1 Hz with a 5 s gap, modelled and filled.

aux = struct("obsNames", {{'lin_accl_x'}}, "variableNames", {{'lin_accl_x'}}, "variableFieldNames", {{'lin_accl_x'}}, "variableUnits", struct("lin_accl_x", "m/s2"), "fileName", "ACT1B_2020-01-01_C_04.txt", "product", "ACT1B");
x = filter(1, [1 -0.7], randn(RandStream("twister", "Seed", 5), 1500, 1));
x(700:704) = NaN;
arc = timeSeriesPreparation.Arc(int64(0:1499)' * int64(1e9), x, aux);
nm = timeSeriesPreparation.noise(arc, [1 0], MaxLag = 50);
[filledArc, info] = timeSeriesPreparation.fill(arc, Method = "collocation", Model = nm, MaxGap = 10);

Limitations

arc.filled is one flag per row (CONCEPT 5), so a row filled on one axis is weighed 0 on every axis. Gaps are filled independently: a neighbouring gap's samples are missing in the window, not predicted. The model is taken as stationary over the window. "reference" is not available yet.
