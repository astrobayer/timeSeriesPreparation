timeSeriesPreparation.internal.provJsonLd

W3C PROV-O graph of an arc's provenance, as JSON-LD text.

Syntax

txt = timeSeriesPreparation.internal.provJsonLd(provenance, Inputs = files, Output = name, Creator = who)
txt = timeSeriesPreparation.internal.provJsonLd(provenance, Inputs = files, Output = name, Creator = who, CreatorOrcid = orcid, Created = when)

Description

The provenance record of an exported day (X-18, CONCEPT 5.2; owner decisions 2026-09-26), written into the NetCDF file and its sidecar. The graph uses the PROV-O classes and properties only: prov:Entity each input L1B file (Inputs), and the output file (Output), which prov:wasGeneratedBy the export activity, prov:wasDerivedFrom every input and prov:wasAttributedTo the creator; prov:Activity each provenance entry of the arc in order (rdfs:label = its stage, prov:startedAtTime = its time), then "export" at Created; the first prov:used the inputs, each later one prov:wasInformedBy the one before; prov:SoftwareAgent timeSeriesPreparation, one per toolbox version in the entries, associated with each activity by prov:wasAssociatedWith; prov:Person the creator, identified by the ORCID URL when CreatorOrcid is given. A stage's detail is kept as the JSON string tsp:detail when it encodes (jsonencode) to at most 4096 characters; otherwise tsp:detail states its length only. Node identifiers are URNs under "urn:timeSeriesPreparation:". Objects are written by containers.Map, whose keys jsonencode sorts, so equal inputs give equal text.

Example

The graph of a two-stage provenance, decoded again.

p = struct("stage", {"mask", "fill"}, "version", "1.2.0", "time", "2026-09-26T17:00:00Z", "detail", struct());
txt = timeSeriesPreparation.internal.provJsonLd(p, Inputs = "ACT1B_2020-01-02_C_04.txt", Output = "2020-01-02.nc", Creator = "A. Author", Created = "2026-09-26T18:00:00Z");
g = jsondecode(txt);

Limitations

The graph records what the arc's provenance says; stages that write no provenance entry are not in it. No PROV-O qualified terms (prov:qualifiedUsage and the like) are written.
