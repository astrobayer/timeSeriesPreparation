timeSeriesPreparation.tsmodels.tsAutoSarima

Grid search over seasonal ARIMA orders minimising AIC or BIC.

Syntax

[best, tbl] = timeSeriesPreparation.tsmodels.tsAutoSarima(x, maxOrder, maxSeasonal, s)
[best, tbl] = timeSeriesPreparation.tsmodels.tsAutoSarima(x, [2 1 2], [1 1 1], 12, Criterion = "bic")
best = timeSeriesPreparation.tsmodels.tsAutoSarima(x, [1 0 0], [1 0 0], 6, Method = "exact", Constant = false)

Description

Chooses the orders of a multiplicative SARIMA(p,d,q)(P,D,Q)_s model when they are not known. Every model of the rectangular grid 0 <= p <= maxp, ..., 0 <= Q <= maxQ except the all-zero one is fitted with tsFitSarima; a fit that fails (too short, not estimable) or has a non-finite criterion is skipped. best is the fit with the smallest criterion, tbl lists all successful fits sorted by it.

The differencing orders d and D are searched too, although the likelihoods of models with different differencing are not strictly comparable: each fit's own AIC/BIC, based on its own nObs, is used as returned by tsFitSarima. For a clean comparison fix d and D (maxd = maxD = 0 on a pre-differenced series). Every option other than Criterion is passed to each tsFitSarima call only when given, so tsFitSarima's own defaults (listed under OPTIONS) apply otherwise. Base MATLAB only.

Accuracy

That of tsFitSarima for each fit; the search itself is exhaustive over the grid. The exact-ML SARIMA likelihood reproduces the direct multivariate-normal density to about 1e-14 (sigtools v1.3.1 HANDOFF, section 3). Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Example

A seasonal AR(1) with period 4 on a small grid.

x = filter(1, [1 0 0 0 -0.6], randn(RandStream("twister", "Seed", 5), 300, 1));
[best, tbl] = timeSeriesPreparation.tsmodels.tsAutoSarima(x, [1 0 0], [1 0 0], 4, Criterion = "bic");

Limitations

The cost grows with the product of the grid sizes, each fit with NStart optimiser starts. AIC/BIC across different d and D are not strictly comparable (see above). Only the tsFitSarima options listed above are forwarded.
