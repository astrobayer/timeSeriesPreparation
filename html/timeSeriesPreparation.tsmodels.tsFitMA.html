timeSeriesPreparation.tsmodels.tsFitMA

Fit an MA(q) model: tsFitArima(x, 0, 0, q, ...).

Syntax

model = timeSeriesPreparation.tsmodels.tsFitMA(x, q)
model = timeSeriesPreparation.tsmodels.tsFitMA(x, q, Method = "css")

Description

Shorthand for the moving-average model x_t - mu = e_t + theta_1 e_(t-1) + ... + theta_q e_(t-q), fitted by timeSeriesPreparation.tsmodels.tsFitArima with p = d = 0; the options given are passed on unchanged, and tsFitArima's defaults apply otherwise. The default is exact Gaussian ML by a Kalman filter, which accepts NaN gaps; Method "css" gives conditional sum of squares. The MA polynomial is invertible by construction (PACF reparametrisation, see tsFitArima).

Accuracy

That of tsFitArima, which it calls; unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Errors

(none of its own) The errors of timeSeriesPreparation.tsmodels.tsFitArima pass through, and so do tsFitArima's refusals of an option outside its domain.

Example

MA(1) with theta = 0.5 and zero mean, by CSS.

x = filter([1 0.5], 1, randn(RandStream("twister", "Seed", 6), 300, 1));
model = timeSeriesPreparation.tsmodels.tsFitMA(x, 1, Method = "css", Constant = false);

Limitations

Those of tsFitArima. Options passed as one struct (inputParser's StructExpand) are no longer accepted; pass name-value pairs.
