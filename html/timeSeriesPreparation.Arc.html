timeSeriesPreparation.Arc

One instrument time series on int64 GPS-ns epochs, with weights, layers and provenance.

Syntax

arc = timeSeriesPreparation.Arc(t, obs, aux)
arc = timeSeriesPreparation.Arc(t, obs, aux, Columns = names, Frame = frame)
arc = addLayer(arc, name, remove)
arc = appendProvenance(arc, stage, detail)
out = derive(arc, t, obs, stage, detail, Units = units)
timeSeriesPreparation.Arc.requireOneRelease(arcs)

Description

The container every stage of this toolbox reads and returns (CONCEPT 5). It is built from gracefoReading's triple [t, obs, aux] by FIELD NAMES - aux.obsNames, variableNames, variableFieldNames, variableUnits and fileName/product (readL1b) or fileNames/products (readL1bMulti) - and calls no gracefoReading function, so it works without the reader installed. Time must be int64 GPS nanoseconds ('TimeFormat' "gpsns"): a double cannot hold 2020-era GPS nanoseconds (about 6.3e17 > 2^53) without rounding. Columns are selected by name; there is no positional fallback.

Release rule (CONCEPT 5.2): the L1B release of every file is read from its name (<PRODUCT>_<date>_<sat>_<RR>), or from the header line "product_version:" when the name does not carry it, and stored in release and provenance. An arc whose files come from more than one release refuses unless AllowMixedRelease is true; requireOneRelease applies the same rule to a campaign (an array of arcs).

Weights and layers: a layer is a named N x 1 logical, true = remove. Layers are additive and can only remove: addLayer refuses to replace a layer, and weights = min over all layers (1 kept, 0 removed). filled is set by the gap stage (X-08) and is all false here. provenance is append-only, one entry per stage: stage, toolbox version, UTC time, detail.

derive is how a stage returns data on new epochs (crnApply, later align): the result keeps names, mission, product, satellite, release, files and frame, carries the provenance and appends the stage's entry; weights, layers and filled start afresh, because they belong to the old epochs.

Accuracy

Exact: t and obs are stored as given, bit for bit, and selecting columns copies them without arithmetic. Weights are exactly 0 or 1.

Example

A ten-sample ACT1B-like arc from a hand-made aux struct.

t = int64(0:9)' * int64(1e9);
aux = struct("obsNames", {{'lin_accl_x'}}, "variableNames", {{'gps_time', 'lin_accl_x'}}, "variableFieldNames", {{'gps_time', 'lin_accl_x'}}, "variableUnits", struct("lin_accl_x", "m/s2"), "fileName", "ACT1B_2020-01-01_C_04.txt", "product", "ACT1B");
arc = timeSeriesPreparation.Arc(t, zeros(10, 1), aux);
arc = addLayer(arc, "demo", (1:10)' > 8);

Limitations

The frame is never inferred: it stays "" unless Frame states it, and a stage that needs a frame refuses (v3 F5). The release is read from the file name or header only; a file stating neither gets release "".
