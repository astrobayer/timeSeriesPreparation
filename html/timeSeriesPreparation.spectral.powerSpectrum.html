timeSeriesPreparation.spectral.powerSpectrum

Power and amplitude spectrum of one series: Welch FFT or Lomb-Scargle.

Syntax

spec = timeSeriesPreparation.spectral.powerSpectrum(t, x)
spec = timeSeriesPreparation.spectral.powerSpectrum(fs, x, Type = "amplitude", NPeaks = 3)
spec = [powerSpectrum(t1, x1, Label = "A"), powerSpectrum(t2, x2, Label = "B")]

Description

The estimation half of sigtools' plotPowerSpectrum, split off at X-02 so that numbers never require a figure (owner decision 2026-09-23). The arithmetic is v1.3.1's, unchanged; TestSigtoolsEquivalence holds it bit for bit against the archive.

An evenly sampled, gap-free series gets a Welch-averaged windowed FFT periodogram; a series with NaN gaps or uneven sampling gets a Lomb-Scargle periodogram (floating-mean GLS by default, Zechmeister and Kuerster 2009). Both use one scaling: power one-sided PSD, unit^2/Hz, S(f) = 2 |X|^2 / (fs sum w^2) amplitude sinusoid amplitude, unit so A sin(2 pi f0 t) peaks at about A in the amplitude spectrum whatever the sampling. The PSD follows sigtools' convention (trapz(f, S) = variance), shared with arma2psd and synthTimeSeries.

FAP gives false-alarm levels for a Lomb-Scargle series: "analytic" uses M = T_span f_max independent frequencies; "bootstrap" shuffles the data over the fixed sampling times NBootstrap times. Both assume a white-noise null; a red-noise record looks over-significant with either. NPeaks returns the highest distinct maxima of the Type quantity, at least MinPeakDistance apart (default the Rayleigh resolution 1/T_span), refined by a 3-point parabola. Several series are one struct array: concatenate the results.

Accuracy

Unchanged from sigtools v1.3.1. A unit sinusoid is recovered at amplitude 1 within the window's scalloping loss (flattop: < 0.01 dB). The Welch dof = 2K is approximate for overlapping segments. The analytic FAP is an approximation (Scargle 1982). The bootstrap level is noisy unless FAP*NBootstrap >= 10, and a warning says so.

Example

A 3 Hz sinusoid at 100 Hz: the amplitude peak is about 1.

t = (0:1/100:20)';
spec = timeSeriesPreparation.spectral.powerSpectrum(t, sin(2*pi*3*t), Type = "amplitude", NPeaks = 1, Window = "flattop");

Limitations

One series per call. The bootstrap FAP draws from the global random stream (randperm); set rng for reproducible levels. Lomb-Scargle costs O(N M) with M frequencies.
