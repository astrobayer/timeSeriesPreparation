timeSeriesPreparation.spectral.sstmcb

Steiglitz-McBride IIR fit to an impulse response (base MATLAB).

Syntax

[b, a] = timeSeriesPreparation.spectral.sstmcb(h, nb, na)
[b, a] = timeSeriesPreparation.spectral.sstmcb(h, nb, na, maxIter)

Description

Fits B(z)/A(z), a(1) = 1, of orders nb and na so that filter(b, a, delta) approximates the impulse response h. It replaces the Signal Processing Toolbox stmcb (unit-impulse input, internal initial denominator) and is psd2arma's Method "stmcb". The method is the Steiglitz-McBride iteration: each pass prefilters the unit impulse and the target h by 1/A_prev (filter), then re-estimates B and A by linear least squares (backslash). This refines the equation-error fit towards the output-error fit, which gives the method its accuracy on rational systems. Exactly maxIter passes are run; there is no convergence test.

Accuracy

sigtools HANDOFF section 3 (NumPy re-derivation of the exact logic): the generating filter is recovered exactly. Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Errors

(none) Non-numeric input, orders that are not non-negative integer scalars, or a maxIter that is not a positive integer are refused by the arguments block with a MATLAB: identifier.

Example

Recover the generating ARMA(2,2) filter from 61 impulse samples.

htrue = filter([1 -0.5 0.2], [1 -1.2 0.6], [1; zeros(60,1)]);
[b, a] = timeSeriesPreparation.spectral.sstmcb(htrue, 2, 2);

Limitations

Unit-impulse input only (no general input/output pair). No stability enforcement. The regressor has L rows and nb+na+1 columns, so h should be several times longer than the model order.

References

K. Steiglitz, L. E. McBride (1965), IEEE Trans. Autom. Control 10(4), 461-464. sigtools v1.3.1 HANDOFF (docs/inputs).
