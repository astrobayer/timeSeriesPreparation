timeSeriesPreparation.bootstrap

Moving-block bootstrap of a statistic, one RNG substream per replicate.

Syntax

[stat, info] = timeSeriesPreparation.bootstrap(x, statFcn)
[stat, info] = timeSeriesPreparation.bootstrap(x, statFcn, NBoot = 1000, BlockLength = [], Seed = 0, Stage = "bootstrap", Level = 0.6827)

Description

Uncertainty of a statistic of serially correlated samples (CONCEPT 6.1, row 7). v2 measured naive sigmas 5-14 times too optimistic on GRACE residuals (CONCEPT 8), because resampling single samples destroys the correlation. The moving-block bootstrap (Kuensch 1989) resamples blocks of BlockLength consecutive rows instead: each replicate joins ceil(N/b) blocks, whose starts are drawn uniformly from 1..N-b+1, and keeps the first N rows. Rows move together, so the correlation between columns is kept.

BlockLength [] takes the automatic rule of internal.blockLength (Politis & White 2004, Patton et al. 2009) per column, rounded up, and the largest over the columns (a longer block keeps more of the dependence; owner decision 2026-09-23).

Replicate r draws from substream r of an mrg32k3a stream seeded by internal.stageSeed(Stage, Seed). The result therefore depends on neither the order nor the number of workers that compute the replicates, and a different stage name gives independent draws (CONCEPT 8).

statFcn maps an N x M matrix to a 1 x K row. It sees NaN where x has NaN (NaN is the only missing value, CONCEPT 5.2), so it must treat them, e.g. mean(z, 1, "omitnan"). No least-squares estimator lives here (CONCEPT 3.2): an application passes its own fit as statFcn.

sigma is the standard deviation of the replicates over those whose statistic is finite; ci the percentile interval at Level, by the linear-interpolation quantile (Hyndman & Fan type 7).

Accuracy

Monte-Carlo accuracy. For the mean of an AR(1) (phi 0.5, N 4000), 200 NumPy realisations with the automatic block and 1000 replicates gave sigma between 0.85 and 1.16 times the exact standard error (mean 0.96; the known small downward bias), where resampling single samples gave 0.53-0.61 (measured 2026-09-23). TestBootstrap holds one realisation to 0.8-1.25.

Example

sigma of the mean of an AR(1): larger than the naive 1/sqrt(N).

x = filter(1, [1 -0.5], randn(RandStream("twister", "Seed", 3), 2000, 1));
[m, info] = timeSeriesPreparation.bootstrap(x, @(z) mean(z, 1, "omitnan"), NBoot = 200);

Limitations

Blocks are stationary in the index, not in time: rows are assumed equally spaced. The percentile interval is first-order accurate; no BCa correction. A statistic with a leading bias is not corrected.
