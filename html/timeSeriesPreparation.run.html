timeSeriesPreparation.run

The instrument stages on one arc, each run when its input is given.

Syntax

res = timeSeriesPreparation.run(arc)
res = timeSeriesPreparation.run(arc, Reference = ref, Config = cfg)
res = timeSeriesPreparation.run(arc, QualFlags = aux, Thrusters = thr, Eclipse = ecl, Events = ev, Soe = soe, User = remove)
res = timeSeriesPreparation.run(arc, Reference = ref, Response = h, Bias = b, Scale = S, Design = X, Statistic = f, Loss = g, Drivers = series)

Description

The single point of access at instrument level (CONCEPT 4). The stages of CONCEPT 6.1 run on one arc, and each runs only when its input exists (owner decision 2026-09-24). A stage without its input is skipped and listed with the reason in diagnostics.skipped; no input is assumed. Each stage is the L2 function of the same name, called with the settings of Config (default Config(arc), the preset of the arc's product).

Execution order. The 6.1 table lists QC before align and align before the CRN consistency stage. QC needs the reference on the observation epochs, and the CRN filter needs the reference on its own raw grid, so run executes those three in data order: crn, align, qc. Every other stage keeps its 6.1 position. The order actually run is diagnostics.stages. mask always: mask(arc, ...) with the sources given (QualFlags, Thrusters, Eclipse, Events, Soe, User) and cfg.mask. Without a source it adds only what the arc itself implies (the SNR layer of a KBR1B/LRI1B preset). crn Reference given and cfg.run.filterReference true: crnApply(ref, crnKernel(cfg.crn.preset), OutputEpochs = arc.t). A reference that is not CRN-filtered is filtered like the L1B data; whether it is, is the caller's statement ([] = not stated, skipped). align Reference given: align(arc, ref) with cfg.align (the filtered reference if crn ran), and checkAlignment with cfg.align; its lag verdicts go to flags. align's layer "alignGap" is added to arc. qc Reference given and arc with 1 or 3 columns: qc.screen on arc and the aligned reference, with Bias, Scale, Response and cfg.qc; the rows it masks on any axis form the layer "qc". Epochs are passed as UTC: GPS minus the leap seconds of the date. noise cfg.noise.order given: noise(s, order) with cfg.noise, s the residual arc (arc minus Bias + Scale x reference, with arc's layers) when a Reference is given, else arc. gate Design given: observability(arc, X) with cfg.unc.minWeightFraction. Its minimum-data refusal stops the run. bootstrap Statistic given: bootstrap(x, Statistic) with cfg.unc, x = s.obs with removed rows NaN. crossval Loss given: crossval(x, Loss) with cfg.unc.folds. fill always: fill(arc, ...) with cfg.fill. "none" reports the gaps. "collocation" fills arc with the noise model, so it needs the noise stage, and a model of arc itself: with a Reference the model is the residual's, and filling arc from it is fill's deferred method "reference", so it is skipped. correlation Drivers given, the noise stage run and cfg.drivers.maxLag given: drivers(arc, Drivers) with cfg.drivers, then correlate(s, drv, model, maxLag) with cfg.unc (NBoot, BlockLength, Level). Seeds: noise, bootstrap and correlate take cfg.run.seed.

Accuracy

Each stage's own; run adds no arithmetic but the residual, obs minus (Bias + reference x Scale'), qc.residuals' formula. A stage's result equals the direct call of that stage on the same inputs, bit for bit (TestRun).

Errors

identifiercausecondition
timeSeriesPreparation:run:campaignDeferredInputarc is an array of arcs; campaign mode (CONCEPT 6.6) is a later work package. The identifiers of the stages propagate; a stage that refuses stops the run.

Example

A 1 Hz ACT1B-like arc against its signal: mask, align, QC, gaps.

t = int64(0:599)' * int64(1e9);
aux = struct("obsNames", {{'lin_accl_x'}}, "variableNames", {{'lin_accl_x'}}, "variableFieldNames", {{'lin_accl_x'}}, "variableUnits", struct("lin_accl_x", "m/s2"), "fileName", "ACT1B_2020-01-02_C_04.txt", "product", "ACT1B");
s = 1e-7 * sin(2 * pi * (0:599)' / 300);
x = s + 1e-9 * randn(RandStream("twister", "Seed", 1), 600, 1);
arc = timeSeriesPreparation.Arc(t, x, aux);
ref = timeSeriesPreparation.Arc(t, s, aux);
res = timeSeriesPreparation.run(arc, Reference = ref);
res.diagnostics.stages

Limitations

One arc per call; campaigns follow (CONCEPT 6.6). qc.screen gets no impulse or jump priors from run. The stage cache (X-14) and the report (X-11) do not exist yet.
