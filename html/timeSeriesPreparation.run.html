timeSeriesPreparation.run

The instrument stages on one arc or a campaign, each run when its input is given.

Syntax

res = timeSeriesPreparation.run(arc)
res = timeSeriesPreparation.run(arcs, Reference = refs, Config = cfg)
res = timeSeriesPreparation.run(arc, Reference = ref, Config = cfg)
res = timeSeriesPreparation.run(arc, QualFlags = aux, Thrusters = thr, Eclipse = ecl, Events = ev, Soe = soe, User = remove)
res = timeSeriesPreparation.run(arc, Reference = ref, Response = h, Bias = b, Scale = S, Design = X, Statistic = f, Loss = g, Drivers = series)

Description

The single point of access at instrument level (CONCEPT 4). The stages of CONCEPT 6.1 run on one arc, and each runs only when its input exists (owner decision 2026-09-24). A stage without its input is skipped and listed with the reason in diagnostics.skipped; no input is assumed. Each stage is the L2 function of the same name, called with the settings of Config (default Config(arc), the preset of the arc's product).

Execution order. The 6.1 table lists QC before align and align before the CRN consistency stage. QC needs the reference on the observation epochs, and the CRN filter needs the reference on its own raw grid, so run executes those three in data order: crn, align, qc. Every other stage keeps its 6.1 position. The order actually run is diagnostics.stages. mask always: mask(arc, ...) with the sources given (QualFlags, Thrusters, Eclipse, Events, Soe, User) and cfg.mask. Without a source it adds only what the arc itself implies (the SNR layer of a KBR1B/LRI1B preset). crn Reference given and cfg.run.filterReference true: crnApply(ref, crnKernel(cfg.crn.preset), OutputEpochs = arc.t). A reference that is not CRN-filtered is filtered like the L1B data; whether it is, is the caller's statement ([] = not stated, skipped). align Reference given: align(arc, ref) with cfg.align (the filtered reference if crn ran), and checkAlignment with cfg.align; its lag verdicts go to flags. align's layer "alignGap" is added to arc. qc Reference given and arc with 1 or 3 columns: qc.screen on arc and the aligned reference, with Bias, Scale, Response and cfg.qc; the rows it masks on any axis form the layer "qc". Epochs are passed as UTC: GPS minus the leap seconds of the date. templates cfg.qc.templates true, qc run on 3 columns and the arc's satellite in the bank: qc.detectTemplates on the qc residual (UTC epochs) with the THR1B firings of Thrusters as priors; each class adds its layer (info.layers, "tplThruster") and its events join flags.events (X-17). noise cfg.noise.order given: noise(s, order) with cfg.noise, s the residual arc (arc minus Bias + Scale x reference, with arc's layers) when a Reference is given, else arc. gate Design given: observability(arc, X) with cfg.unc.minWeightFraction. Its minimum-data refusal stops the run. bootstrap Statistic given: bootstrap(x, Statistic) with cfg.unc, x = s.obs with removed rows NaN. crossval Loss given: crossval(x, Loss) with cfg.unc.folds. fill always: fill(arc, ...) with cfg.fill. "none" reports the gaps. "collocation" fills arc with the noise model, so it needs the noise stage, and a model of arc itself: with a Reference the model is the residual's, and filling arc from it is fill's deferred method "reference", so it is skipped. correlation Drivers given, the noise stage run and cfg.drivers.maxLag given: drivers(arc, Drivers) with cfg.drivers, then correlate(s, drv, model, maxLag) with cfg.unc (NBoot, BlockLength, Level). Seeds: noise, bootstrap and correlate take cfg.run.seed.

Stage cache (X-14, CONCEPT 6.6; owner decisions 2026-09-25). With cfg.run.cacheDir set, the expensive stages crn, qc, noise and correlation keep their outputs in cacheDir/<stage>/<key>.mat. The key is the SHA-256 (internal.contentHash) of the stage, the toolbox version, the stage's inputs (arcs by content, not provenance) and its settings. A stored key is loaded instead of computed. Each cacheable stage run gets a row in diagnostics.cache (hit, miss, rewritten, unsaved, or off), and the run entry of provenance carries the table. bootstrap and crossval take a function handle, which cannot be hashed, so they are never cached; their row says so. The cheap stages (mask, align, gate, fill) always compute. "" (the default) is off (R5).

Campaign mode (X-15, CONCEPT 6.6 and 5.2; owner decisions 2026-09-26). An Arc array of two or more arcs is a campaign: every arc runs the stages above, and a stage that refuses on one arc stops only that arc; its MException is kept and the campaign continues. inputs Reference and Thrusters may be an Arc array, QualFlags, Eclipse, User and Design a cell, with one entry per arc; any other value is shared by all arcs. seeds arc k runs with cfg.run.seed + k - 1: it equals the single run of arcs(k) with that seed. Without a Config, arc k takes Config(arcs(k)); the campaign settings come from Config(arcs(1)). release the arcs share one L1B release unless cfg.run.mixedRelease is true (Arc.requireOneRelease). parallel cfg.run.parallel = true runs the arcs in parfor when canUseParallelPool is true, else serially; the seeds make both equal. res.parallel says which ran. storage with cfg.run.outDir set, each arc's result goes to the MAT v7.3 file outDir/<mission>/<satellite>/<yyyy>/ <yyyy-mm-dd>.mat (GPS date of its first epoch) as result, with schemaVersion "1"; an existing file is kept unless cfg.run.overwrite is true (status "unsaved"), and a file this campaign wrote is never overwritten. outDir/manifest.json records the campaign (software, dates, config hash and seed, and per arc its source files, content hash, file, SHA-256, status). "" (the default) keeps everything in memory (R5).

Accuracy

Each stage's own; run adds no arithmetic but the residual, obs minus (Bias + reference x Scale'), qc.residuals' formula. A stage's result equals the direct call of that stage on the same inputs, bit for bit (TestRun).

Errors

The identifiers of the stages propagate; a stage that refuses stops the run, or in a campaign that arc. Arc:mixedRelease propagates from Arc.requireOneRelease.

Example

A 1 Hz ACT1B-like arc against its signal: mask, align, QC, gaps.

t = int64(0:599)' * int64(1e9);
aux = struct("obsNames", {{'lin_accl_x'}}, "variableNames", {{'lin_accl_x'}}, "variableFieldNames", {{'lin_accl_x'}}, "variableUnits", struct("lin_accl_x", "m/s2"), "fileName", "ACT1B_2020-01-02_C_04.txt", "product", "ACT1B");
s = 1e-7 * sin(2 * pi * (0:599)' / 300);
x = s + 1e-9 * randn(RandStream("twister", "Seed", 1), 600, 1);
arc = timeSeriesPreparation.Arc(t, x, aux);
ref = timeSeriesPreparation.Arc(t, s, aux);
res = timeSeriesPreparation.run(arc, Reference = ref);
res.diagnostics.stages

Limitations

qc.screen gets no impulse or jump priors from run. A campaign keeps all results in memory besides writing them; the day files are not locked against a second process. The report (X-11) does not exist yet. The cache has no eviction and no locking (internal.stageCache).
