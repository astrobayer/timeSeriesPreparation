timeSeriesPreparation.internal.stageSeed

RNG seed of a stage: its name hashed, plus the caller's seed.

Syntax

seed = timeSeriesPreparation.internal.stageSeed(stage, seed0)

Description

CONCEPT 8: "RNG substream per replicate, seed per stage name". Each random stage draws from its own seed, so that adding or removing a stage never changes another stage's numbers. The seed is the 32-bit FNV-1a hash of the stage name's UTF-8 bytes plus seed0, modulo 2^32: a valid RandStream seed. The arithmetic is exact (uint64).

Inputs

namesizetypedefaultdescription
stage1,1string—- Stage name, e.g. "bootstrap".
seed01,1double—- Caller's seed, integer >= 0.

Outputs

namesizetypedefaultdescription
seed1,1double—- Integer in [0, 2^32).

Accuracy

Exact: integer arithmetic. FNV-1a of "a" is 0xE40C292C and of "foobar" 0xBF9CF968, computed from the definition in Python (2026-09-23); TestBootstrap pins both.

Errors

(none)

Example

The seed of the bootstrap stage with the caller's seed 0.

seed = timeSeriesPreparation.internal.stageSeed("bootstrap", 0);

Limitations

A hash, not an injection: two names can share a seed (probability 2^-32 per pair).

References

Fowler, G., Noll, L. C., Vo, K.-P., Eastlake, D. The FNV Non-Cryptographic Hash Algorithm. IETF Internet-Draft draft-eastlake-fnv (FNV-1a, 32 bit: offset basis 2166136261, prime 16777619).
