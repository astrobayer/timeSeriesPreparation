timeSeriesPreparation.internal.dlyap

Stationary covariance P = T P T' + Q, the one Lyapunov solver of the toolbox.

Syntax

P = timeSeriesPreparation.internal.dlyap(T, Q, tol, maxIter)

Description

Solves the discrete Lyapunov equation P = T*P*T' + Q for the stationary state covariance of a stable state-space model. It uses the doubling iteration P <- P + A*P*A', A <- A*A (Anderson and Moore), O(r^3) per step and well behaved for a stable T. It stops when the Frobenius change falls to tol times max(||P||, 1), and falls back to the direct Kronecker solve (I - kron(T, T)) \ Q(:) when maxIter steps do not converge or the iterate is not finite (eigenvalues at the unit circle). The result is symmetrised.

sigtools v1.3.1 carried five copies of this routine, which differed only in tol and maxIter: arma2acv 1e-15 and 80, synthTimeSeries and tsFitSarima 1e-14 and 80, tsFitArima and tsForecast 1e-14 and 60. X-02 made them one function (owner decision 2026-09-23). Each caller passes its own values, so every result is bit-identical to v1.3.1.

Inputs

namesizetypedefaultdescription

Accuracy

The doubling iterate matches the Kronecker solve to about 1e-15 relative (sigtools HANDOFF section 3, NumPy re-derivation). The arithmetic is that of the v1.3.1 copies, operation for operation, so TestSigtoolsEquivalence holds every caller's output bit for bit.

Errors

(none)

Example

AR(1) with phi = 0.9: the stationary variance is 1/(1 - 0.81).

P = timeSeriesPreparation.internal.dlyap(0.9, 1, 1e-14, 60);

Limitations

The Kronecker fallback costs O(r^6) and r^4 memory; it is meant for the small state dimensions of ARMA models.

References
