timeSeriesPreparation.tsmodels.tsFitAR

Fit an AR(p) model: tsFitArima(x, p, 0, 0, ...).

Syntax

model = timeSeriesPreparation.tsmodels.tsFitAR(x, p)
model = timeSeriesPreparation.tsmodels.tsFitAR(x, p, Method = "yw")

Description

Shorthand for the autoregressive model x_t - mu = phi_1 (x_(t-1) - mu) + ... + phi_p (x_(t-p) - mu) + e_t, fitted by timeSeriesPreparation.tsmodels.tsFitArima with d = q = 0; the options given are passed on unchanged, and tsFitArima's defaults apply otherwise. The default is exact Gaussian ML by a Kalman filter, which accepts NaN gaps; Method "css" gives conditional sum of squares and "yw" the closed-form Yule-Walker estimate. tsFitArima describes the reparametrisation, the multi-start search and the standard errors.

Accuracy

That of tsFitArima, which it calls; unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Errors

(none of its own) The errors of timeSeriesPreparation.tsmodels.tsFitArima pass through, and so do tsFitArima's refusals of an option outside its domain.

Example

AR(2) with phi = [0.5 -0.3], Yule-Walker.

x = filter(1, [1 -0.5 0.3], randn(RandStream("twister", "Seed", 5), 500, 1));
model = timeSeriesPreparation.tsmodels.tsFitAR(x, 2, Method = "yw");

Limitations

Those of tsFitArima. Options passed as one struct (inputParser's StructExpand) are no longer accepted; pass name-value pairs.
