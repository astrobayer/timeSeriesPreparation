timeSeriesPreparation.partialCorrelation

Partial correlation of each pair of columns given all others, with block-bootstrap sigmas.

Syntax

res = timeSeriesPreparation.partialCorrelation(X)
res = timeSeriesPreparation.partialCorrelation(X, Names = [], NBoot = 1000, BlockLength = [], Seed = 0, Stage = "partialCorrelation", Level = 0.6827)

Description

The partial correlation of CONCEPT 7 (e.g. a residual against beta' with the eclipse fraction held fixed): the correlation of columns i and j after the linear effect of every other column is removed from both. It is read from the inverse Q of the correlation matrix of the complete rows, rho_ij.rest = -Q_ij / sqrt(Q_ii Q_jj), with 1 on the diagonal. With two columns it is their ordinary correlation. sigma and ci come from a moving-block bootstrap of the rows (bootstrap; automatic Politis-White block length unless BlockLength; seed from Stage and Seed), because rows in time order are serially correlated (CONCEPT 8).

Accuracy

r equals the correlation of the residuals of i and j each regressed on the other columns (TestPartialCorrelation holds 1e-12) and, for three columns, (r_ij - r_ik r_jk) / sqrt((1 - r_ik^2)(1 - r_jk^2)). Its conditioning is that of the correlation matrix; nearly dependent columns refuse.

Example

A residual that depends on beta' only, beta' and eclipse correlated.

rs = RandStream("twister", "Seed", 22);
beta = randn(rs, 500, 1);
eclipse = 0.7 * beta + randn(rs, 500, 1);
residual = 0.5 * beta + randn(rs, 500, 1);
res = timeSeriesPreparation.partialCorrelation([residual beta eclipse], Names = ["residual" "betaPrime" "eclipse"], NBoot = 200);

Limitations

Linear and Gaussian in spirit; outliers act on r directly. The rows used are those complete in every column.

References
