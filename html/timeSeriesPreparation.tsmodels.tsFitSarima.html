timeSeriesPreparation.tsmodels.tsFitSarima

Fit a seasonal ARIMA(p,d,q)(P,D,Q)_s model by CSS or exact ML.

Syntax

model = timeSeriesPreparation.tsmodels.tsFitSarima(x, order, seasonal, s)
model = timeSeriesPreparation.tsmodels.tsFitSarima(x, [1 0 1], [1 1 0], 12, Method = "exact", NStart = 5)

Description

Fits the multiplicative seasonal ARIMA model phi(B) PHI(B^s) (1-B)^d (1-B^s)^D (x_t - mu) = theta(B) THETA(B^s) e_t with e_t ~ N(0, sigma^2). x is differenced d times by (1-B) and then D times by (1-B^s); the seeds are kept in diffInfo for tsForecast. The non-seasonal and seasonal operators are multiplied out into one long ARMA polynomial pair in B (arExpanded, maExpanded), which is evaluated by conditional sum of squares ("css", the default: the first max(p + sP, q + sQ) residuals set to zero) or by exact Gaussian ML ("exact": a Kalman filter on the companion state space of the expanded ARMA, started from the stationary covariance of the shared doubling solver timeSeriesPreparation.internal.dlyap, tolerance 1e-14, 80 doublings, Kronecker fallback; sigma^2 concentrated out).

Each of the four operators is optimised in an unconstrained space: tanh maps to partial autocorrelations in (-1, 1), clamped to +/-0.999, and the Durbin-Levinson recursion gives the coefficients, so every trial operator is stationary and invertible by construction. fminsearch (TolX = TolFun = 1e-8, MaxFunEvals 2000 (p+q+P+Q+2)) runs from NStart starts: the white-noise point and NStart - 1 points perturbed by 0.3 randn; the lowest negative log-likelihood wins. AIC = 2 nll + 2 k, BIC = 2 nll + k log(nObs), with k the number of coefficients plus one for sigma^2.

A seasonal order needs s >= 2; with P = D = Q = 0 the period is ignored and the fit is a plain ARIMA, matching tsFitArima up to the optimiser. The exact method also accepts NaN gaps on a regular time grid: the Kalman filter only predicts there and accrues no likelihood term, which gives the exact ML estimate on the observed data. Gaps require d = D = 0. Base MATLAB only.

Accuracy

Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit. The sigtools HANDOFF (section 3) records that the expanded-ARMA Kalman filter reproduces the direct multivariate-normal concentrated log-likelihood to about 1e-14, both for a complete series and with missing samples (gap filter against the density of the observed subset: exact to 0). The optimum is only as good as fminsearch from NStart starts (TolX 1e-8).

Example

A seasonal AR(1) with period 12 and PHI = 0.5, fitted by CSS.

x = filter(1, [1 zeros(1, 11) -0.5], randn(RandStream("twister", "Seed", 3), 240, 1));
model = timeSeriesPreparation.tsmodels.tsFitSarima(x, [0 0 0], [1 0 0], 12, Constant = false);

Limitations

No standard errors. The perturbed starts draw from the global random stream, whose state is restored afterwards; the fit therefore depends on the current rng state (set rng for a reproducible fit). The expanded ARMA has order p + sP and q + sQ, so the exact method costs O(n r^3) per evaluation with r = max(p + sP, q + sQ + 1) and is slow for long seasons. Gaps and differencing do not mix. Options passed as one struct (inputParser's StructExpand) are no longer accepted; pass name-value pairs.
