timeSeriesPreparation.mask

Named removal layers from flags, event lists, thrusters, eclipse, SNR and the caller.

Syntax

[arc, info] = timeSeriesPreparation.mask(arc)
[arc, info] = timeSeriesPreparation.mask(arc, QualFlags = aux, Thrusters = thr, Events = ev)
[arc, info] = timeSeriesPreparation.mask(arc, Soe = soe, Eclipse = ecl, User = remove)

Description

Stage 1 of CONCEPT 6.1. Each source below becomes one named layer of the arc (true = remove, Arc.addLayer), so a sample's weight is 0 as soon as one layer removes it and every removal keeps its reason. A source that is not given adds no layer. Product defaults come from Config(arc).mask (owner decisions 2026-09-24): - qualflg: aux of the same file(s) (readL1b / readL1bMulti) is decoded with gracefoReading.decodeQualFlags, whose bit meanings are the file header's own. Each bit in RemoveBits becomes a layer "qualflg_b<k>". The presets remove the phase break (KBR1B and LRI1B bit 0) and the L1B fill flags, "interpolated data point (due to gap)" (ACT1B bits 5-7, KBR1B and LRI1B bits 6-7). Every other bit is reported in info.qualflg and removes nothing: the ACT1B clock-offset extrapolation (bits 3/4), the KBR1B time-tag bias correction (bit 5), the ACT1B Vp and residual bits (0, 2). - snr: every observation whose name contains "SNR" and whose median is positive; a sample is removed where one of them is below SnrFraction times its median over the arc (layer "snr"; preset 0.5 for KBR1B and LRI1B, provisional). - Thrusters: a THR1B Arc; every record with a positive on_time_* removes [t - ThrMargin, t + max on-time + ThrMargin] (layer "thr"). The default margin is half the fit interval Tf of the product's CRN preset (crnKernel: 70.35 s ACC, 35.35 s KBR), the reach of a filtered firing. - Eclipse: a driver series (t, value in [0, 1], the illuminated fraction). Every sample of it strictly inside (0, 1), and every step between two samples whose values differ, is a transition; the transitions widened by EclipseMargin (default as ThrMargin) are removed (layer "eclipse"). - Events and Soe: official event lists (G-05). Events is a table of windows the caller states (tStart, tEnd int64 GPS ns, source, text), for instance a TN-01a entry, whose prose is never parsed here. Soe is gracefoReading.readEventList's TN-01 table (TimeFormat "mjd"): its enabled MANV rows of the arc's satellite (both for "Y") become windows [epoch, epoch + values(1) s]. That values(1) is the duration was measured: the first GRACE-C MANV row (2018-05-24, 127 s) is TN-01a's "calibration maneuver from 06:19:26 to 06:21:33" to the second. All windows remove (layer "events") and are returned as calibration windows in info.windows. - CrnEdge: samples within half the CRN fit interval of a gap (a step above 1.5 median steps) are removed (layer "crnEdge"). Off by default: an L1B product already stops where its filter window runs out. - User: an N x 1 logical of the caller (layer "user"). Jumps are never masked here; they are qc's (CONCEPT 6.1, row 2).

Accuracy

Exact: layers are comparisons of int64 epochs and of the stored values; margins are rounded to whole nanoseconds.

Example

A user layer on a ten-sample arc; weights follow the layers.

t = int64(0:9)' * int64(1e9);
aux = struct("obsNames", {{'lin_accl_x'}}, "variableNames", {{'gps_time', 'lin_accl_x'}}, "variableFieldNames", {{'gps_time', 'lin_accl_x'}}, "variableUnits", struct("lin_accl_x", "m/s2"), "fileName", "ACT1B_2020-01-01_C_04.txt", "product", "ACT1B");
arc = timeSeriesPreparation.Arc(t, zeros(10, 1), aux);
[arc, info] = timeSeriesPreparation.mask(arc, User = (1:10)' > 8);

Limitations

Classic GRACE decimal qualflg is not decoded (gracefoReading reads bit strings only; X-13). LRI has no CRN preset (V-2), so its margins must be given. TN-01a windows are the caller's reading of the list.
