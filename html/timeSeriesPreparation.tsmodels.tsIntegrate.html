timeSeriesPreparation.tsmodels.tsIntegrate

Inverse of tsDiff: reconstruct a series from its differences.

Syntax

x = timeSeriesPreparation.tsmodels.tsIntegrate(y, x0)

Description

Undoes y = (1-B)^d x of tsDiff, for instance to bring a forecast of the differenced series back to the original scale. Starting from the deepest level, each step prepends the stored initial value x0(i) and cumulatively sums: x = x0(i) + [0; cumsum(y)]. With d = numel(x0) levels the result is d samples longer than y; an empty x0 returns y. Base MATLAB only.

Inputs

namesizetypedefaultdescription
y:,1double—- Differenced series, finite. A matrix is read as y(:).
x0:,1double—- Initial value per differencing level, as returned by tsDiff; [] for d = 0.

Outputs

namesizetypedefaultdescription
xM+d,1double—- Reconstructed series on the original scale.

Accuracy

Exact up to rounding in the cumulative sums; tsIntegrate(tsDiff(x, d)) returns x to rounding. Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Errors

(none) A non-numeric, complex or non-finite y, or a non-numeric x0, is refused by the arguments block with a MATLAB: identifier.

Example

Difference twice and rebuild.

x = ((1:10)').^2;
[y, x0] = timeSeriesPreparation.tsmodels.tsDiff(x, 2);
xr = timeSeriesPreparation.tsmodels.tsIntegrate(y, x0);

Limitations

Lag-1 levels only, matching tsDiff. The rounding error of the cumulative sums grows with the length and with d.

References

G. E. P. Box, G. M. Jenkins, G. C. Reinsel, Time Series Analysis: Forecasting and Control, Wiley. sigtools v1.3.1 HANDOFF (docs/inputs).
