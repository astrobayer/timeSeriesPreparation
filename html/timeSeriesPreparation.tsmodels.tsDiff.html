timeSeriesPreparation.tsmodels.tsDiff

Apply d-th order lag-1 differencing: y = (1-B)^d x.

Syntax

y = timeSeriesPreparation.tsmodels.tsDiff(x)
[y, x0] = timeSeriesPreparation.tsmodels.tsDiff(x, d)

Description

Differencing removes a stochastic trend before an ARMA model is fitted (the "I" of ARIMA): y = (1-B)^d x, with B the lag operator, applied as d successive diff calls. x0(i) keeps the first value at level i, so tsIntegrate(y, x0) rebuilds x exactly. d = 0 passes the series through, NaN gaps included; for d > 0 the series must be finite, because a difference across a missing sample is undefined. Base MATLAB only.

Inputs

namesizetypedefaultdescription
x:,1double—- Series. A matrix is read as x(:).
d1,1double—- Differencing order >= 0, rounded; [] or omitted: 0.

Outputs

namesizetypedefaultdescription
yN-d,1double—- Differenced series (1-B)^d x.
x0d,1double—- First value at each differencing level, for tsIntegrate.

Accuracy

Exact up to rounding in the differences. Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Errors

identifiercausecondition
timeSeriesPreparation:tsDiff:negativeOrderOrderd < 0.
timeSeriesPreparation:tsDiff:tooShortOrderd >= numel(x).
timeSeriesPreparation:tsDiff:nonfiniteWithDiffGapsd > 0 and x holds NaN or Inf.

Example

Second differences of a quadratic are constant.

x = ((1:10)').^2;
[y, x0] = timeSeriesPreparation.tsmodels.tsDiff(x, 2);

Limitations

Lag-1 differencing only; seasonal differencing (1-B^s)^D lives in tsFitSarima. No differencing across gaps.
