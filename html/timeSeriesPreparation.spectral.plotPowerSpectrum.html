timeSeriesPreparation.spectral.plotPowerSpectrum

Draw spectra from powerSpectrum: lines, peaks, FAP levels, confidence bars.

Syntax

h = timeSeriesPreparation.spectral.plotPowerSpectrum(spec)
h = timeSeriesPreparation.spectral.plotPowerSpectrum(spec, Confidence = 0.95, Unit = "nT")

Description

The drawing half of sigtools' plotPowerSpectrum, split at X-02 (owner decision 2026-09-23): it computes nothing but the placement of the display elements. It takes the struct array from powerSpectrum and draws each series in the quantity that series was computed for (spec.type), on log-log axes by default. It also draws the peaks returned by powerSpectrum (triangles), and each Lomb-Scargle series' false-alarm levels as dashed lines labelled with their confidence. Confidence adds a chi-square confidence bar for each FFT/Welch series (dof = spec.dof). ShowSpectralWindow adds a lower panel with the spectral window |W(f)|^2 of each Lomb-Scargle series, to judge alias peaks.

Accuracy

Not applicable, because the function draws and computes no result. The confidence bar's factors solve gammainc(x/2, dof/2) = p with fzero, as in sigtools v1.3.1.

Errors

Example

Two series, one figure; the peaks come from powerSpectrum.

t = (0:1/100:20)';
spec = [timeSeriesPreparation.spectral.powerSpectrum(t, sin(2*pi*3*t), Label = "A", Type = "amplitude", NPeaks = 1), timeSeriesPreparation.spectral.powerSpectrum(t, 0.5*sin(2*pi*7*t), Label = "B", Type = "amplitude")];
h = timeSeriesPreparation.spectral.plotPowerSpectrum(spec, Unit = "nT");
close(h.figure);

Limitations

One figure per call. The spectral-window panel needs a new figure, so it is ignored when Axes is given.
