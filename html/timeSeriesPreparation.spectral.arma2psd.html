timeSeriesPreparation.spectral.arma2psd

One-sided PSD (or ASD) of a discrete-time ARMA process.

Syntax

[S, f] = timeSeriesPreparation.spectral.arma2psd(b, a, Fs)
[S, f, info] = timeSeriesPreparation.spectral.arma2psd(b, a, Fs, NoiseVariance = 2, NFreq = 4096)

Description

Returns the spectral density of the stationary ARMA process x[n] = filter(b, a, w[n]), w white with variance sigma_w^2, sampled at Fs. It is the inverse of psd2arma and uses the same scaling,

S(f) = (2 sigma_w^2/Fs) |H(f)|^2, H = B(z)/A(z), z = exp(-2i pi f/Fs),

so that trapz(f, S) is the process variance sigma_w^2 sum(psi^2). H is evaluated with sfreqz on NFreq+1 points from 0 to Fs/2, or on the given Frequencies. Sided "two" returns the two-sided level (sigma_w^2/Fs)|H|^2; Output "asd" returns sqrt(S). info.variance is always the trapz of the one-sided PSD. The model's roots are reported, not checked: an unstable A still gives a spectrum.

Accuracy

sigtools HANDOFF section 3 (NumPy re-derivation): the Parseval identity trapz(f,S) = sigma_w^2 sum(psi^2) holds to ratio 1.0, up to the trapezoidal quadrature error of the grid. Unchanged from sigtools v1.3.1; TestSigtoolsEquivalence holds it bit for bit.

Example

PSD of an ARMA(2,2) process at 500 Hz with noise variance 2.

[S, f, info] = timeSeriesPreparation.spectral.arma2psd([1 -0.5 0.2], [1 -1.2 0.6], 500, NoiseVariance = 2);

Limitations

Discrete-time model only; the spectrum is periodic in Fs and is returned up to Fs/2. info.variance is a trapezoidal sum on the chosen grid, so a coarse grid under-resolves sharp peaks.
