timeSeriesPreparation.exportNetcdf

One arc, its residual and QC events as a CF-1.12/ACDD-1.3 NetCDF-4 file with PROV-O provenance.

Syntax

info = timeSeriesPreparation.exportNetcdf(file, arc, Metadata = m)
info = timeSeriesPreparation.exportNetcdf(file, arc, Residual = s, Events = T, Metadata = m, Overwrite = true)

Description

The exchange format of a prepared day (X-18, CONCEPT 5.2; owner decisions 2026-09-26). The file is NetCDF-4 (deflate 4, shuffle) and states Conventions "CF-1.12, ACDD-1.3". Variables: time int64 GPS nanoseconds, arc.t bit for bit: units "nanoseconds since 2000-01-01 12:00:00", calendar "standard", units_metadata "leap_seconds: none" (GPS counts no leap seconds; CF 1.12 section 4.4, kept by the owner although CF 1.13 withdrew the attribute in favour of the calendar "tai"). <name> each observation column, double, named and with the units of arc.names and arc.units; NaN is the _FillValue. weights arc.weights, units "1". filled byte 0/1 (flag_values, flag_meanings "measured filled"). layers uint32, bit j-1 set where layer j removes the sample; flag_masks and flag_meanings give the bits and the layer names (absent without layers). residual_<name> with Residual: its columns, same epochs. event_* with Events, on dimension "event": event_start, event_end (int64 GPS ns, as time), event_class, event_axis, event_source (byte codes with flag_values and flag_meanings), event_amplitude, event_sigma, event_confidence. Global attributes: the ACDD 1.3 set (title, summary, keywords, id, history, source, platform, instrument, processing_level, product_version, date_created, creator_name/_email/_url/_type/_institution, institution, publisher_name, license, project, time_coverage_start/ _end/_duration/_resolution), l1b_release, frame, schema_version ("1", the layout above), observation_variables and residual_variables (the names in column order), event_count (-1 without Events, else their number), and prov_jsonld, the PROV-O graph of the arc's provenance (internal.provJsonLd). The same graph is written to the sidecar <file name>.prov.jsonld beside the file. id is the SHA-256 of t and obs (internal.contentHash), so equal data give equal ids.

Accuracy

time, the observations, weights, filled, layers and the residual are written as stored: readNetcdf returns them bit for bit (TestExport). Event epochs are UTC datetimes; their GPS nanoseconds come from a duration and are exact to about 1 microsecond.

Example

A ten-sample arc with one layer to a temporary file, and back.

t = int64(7306 * 86400 - 43200 + 18) * int64(1e9) + int64(0:9)' * int64(1e9);
aux = struct("obsNames", {{'lin_accl_x'}}, "variableNames", {{'lin_accl_x'}}, "variableFieldNames", {{'lin_accl_x'}}, "variableUnits", struct("lin_accl_x", "m/s2"), "fileName", "ACT1B_2020-01-02_C_04.txt", "product", "ACT1B");
arc = addLayer(timeSeriesPreparation.Arc(t, (1:10)' * 1e-9, aux), "user", (1:10)' > 8);
f = tempname + ".nc";
info = timeSeriesPreparation.exportNetcdf(f, arc, Metadata = struct("creator", "A. Author"));
back = timeSeriesPreparation.readNetcdf(f);
delete(f, info.prov);

Limitations

Global attributes are written as NetCDF char; keep the metadata ASCII. The events are a plain table on dimension "event", not a CF discrete-sampling geometry. At most 32 layers.
