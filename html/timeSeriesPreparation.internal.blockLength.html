timeSeriesPreparation.internal.blockLength

Automatic block length for block resampling (Politis-White, Patton correction).

Syntax

[b, info] = timeSeriesPreparation.internal.blockLength(x)

Description

The block length that minimises the MSE of the block-bootstrap variance estimator of the mean, estimated per column by Politis & White (2004) with the correction of Patton, Politis & White (2009). bootstrap and crossval use it when no BlockLength is given (owner decision 2026-09-23).

With n samples, K_N = max(5, ceil(sqrt(log10 n))), m_max = ceil(sqrt n) + K_N and the band c sqrt(log10(n)/n), c = 2: 1. rho(k), k = 1..m_max, the correlation of x(t) with x(t-k) over the common sample t = m_max+1..n. 2. mhat is the first lag L with rho(L..L+K_N-1) all inside the band; if there is none, the largest lag outside it. M = 2 mhat, capped at m_max. 3. With R(k) the covariance of x(t) and x(t-k) over t = M+1..n (N-1 normalisation) and the flat-top window lambda(s) = 1 for |s| < 1/2, 2(1-|s|) up to 1: G = sum_{|k|<=M} lambda(k/M) |k| R(k), D = 4/3 (sum_{|k|<=M} lambda(k/M) R(k))^2, b = (2 G^2 / D)^(1/3) n^(1/3), capped at ceil(min(3 sqrt n, n/3)). D is the circular (and moving) block bootstrap's constant. These are the steps of Patton's reference implementation (opt_block_length_REV_dec07). A NaN sample is left out of every sum it would enter (pairwise-complete moments). A column without variance gets b = 1.

Accuracy

A NumPy transcription of these steps equals recombinator 0.0.6.1 (a port of Patton's code) to 3e-14 relative on six AR(1) series (phi -0.6 to 0.99, n 500 to 20000), measured 2026-09-23. That port returns mhat 0-based in the no-window branch of step 2; this function returns the lag, as Patton's MATLAB find does. tests/oracles/block_length_pw.json pins the numbers.

Example

An AR(1) with phi = 0.9: a block of about 50 samples.

x = filter(1, [1 -0.9], randn(RandStream("twister", "Seed", 1), 2000, 1));
b = timeSeriesPreparation.internal.blockLength(x);

Limitations

Built for the variance of the mean; for other statistics it is a guide, not an optimum. Columns are treated one by one.
